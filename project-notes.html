SmartStudy Tools Project Notes

This project started as a first website and is now being upgraded step by step into a real student utility platform.

Current version A responsive student tool hub with 14 calculators, converters, productivity tools, dark mode, animations, and PWA basics.
Main goal Make a practical, clean, and portfolio-quality project that students can actually use.
Publishing plan After your visual verification, we will push to GitHub and publish using GitHub Pages.

Completed improvements

  • Modern homepage and tools dashboard
  • Search and category filtering
  • SVG icons instead of emojis
  • Animated UI with reduced-motion support
  • Reusable CSS and JavaScript structure
  • Better validation and copy-result buttons
  • Dark mode with saved preference
  • Basic offline/PWA support

Available tools

  • Math Calculator
  • Percentage Calculator
  • Loan EMI Calculator
  • Age Calculator
  • Unit Converter
  • Table Generator
  • GPA Calculator
  • CGPA Calculator
  • Marks Calculator
  • BMI Calculator
  • LCM & HCF Calculator
  • Fraction Calculator
  • Word Counter
  • Pomodoro Timer
