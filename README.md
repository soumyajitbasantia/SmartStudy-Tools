# SmartStudy Tools

SmartStudy Tools is a free, fast, responsive collection of web tools designed for students. It includes calculators, converters, productivity utilities, and practice tools that help with everyday study tasks.

## Features

- Modern homepage and searchable tools dashboard
- Category filter for tools
- Math calculator for basic arithmetic
- Percentage calculator with multiple calculation modes
- Loan EMI calculator with total payment and total interest
- Age calculator with next birthday countdown
- Unit converter for length, weight, and temperature
- Multiplication table generator with custom range
- GPA / SGPA calculator
- Word counter with reading and speaking time estimates
- Pomodoro study timer
- Fraction calculator
- LCM & HCF calculator
- Marks percentage calculator
- CGPA calculator
- BMI calculator
- Copy-result buttons
- Dark mode with saved preference
- Mobile-first responsive layout
- Basic PWA/offline support through a service worker
- Shared design system using reusable CSS

## Tech Stack

- HTML
